# iron-Xで人追従を試す

[English](ironx-follow.md)

監視付きの実験用です。共通UIは実機での再検証が必要で、過去のスマホ追従試験を
このUIの動作保証として扱わないでください。

## 動かさずに準備

1. [iron-Xネットワーク接続](ironx-network.ja.md)に従います。ROS・telemetry・watchdog bridge・
   gatewayはiron-X、Kitサーバー（`APRIS_ADAPTER=ironx_network`）とPWAはPCで動かします。
   driverやNode-REDの走行送信者を重複起動しないでください。
2. [HTTPSと証明書の信頼](../local-https.ja.md)を準備します。固定したiPhoneから
   `https://<PCのLANアドレス>:<HTTPSポート>/service?service=carry`を開きます。
   実際の起動ポートを使い、ロボットのアドレスやスマホのlocalhostとは区別してください。
3. **Start vision**でカメラを許可し、前向きのカメラを選んで上半身の観測を確認します。
   Safariを前面に保ち、スマホをロックしないでください。
4. 他タブの操作権を解放します。前後左右を確認し、物理停止・電源を操作できるようにして、
   動かす前に操作者の許可を得ます。

LLMキーは不要です。旧専用UIの音声・LLM操作は共通パネルにありません。
Advanced controlsのミッション解釈は別の操作経路です。

## 開始と停止

1. **Acquire control → Confirm clear path · 30 s → Start service**の順に操作します。
   開始すると検出人物へ接近する場合があります。
2. **Yes → Items are loaded**と回答します。カメラに写る範囲でゆっくり歩きます。
3. **We have arrived**は追従を終えて停止を確認します。
   **Cancel and stop**は中断、**Emergency stop**は停止をラッチします。
4. 次の試験や操作権の引き継ぎ前に、実際の停止を確認してください。

**現在の制約：**30秒は前方確認から数え、サービス開始・積載完了からではありません。
開始しても許可は更新せず、旧Carry専用UIの自動更新は引き継がれていません。
失効すると前方確認が取り消され前進を制限し、サービスを中断する場合があります。
全指令が正確に30秒で停止する保証ではありません。
中断・実停止・周囲を確認してから再許可し、明示的に再開してください。
試験延長のために安全判定を無効化しないでください。[共通実機操作](../demos/hardware-playground.ja.md)も参照。

## 復旧

- 目標距離での停止は正常な待機の場合があります。追従実行中なら離れると再開する場合があります。
- 対象喪失・古い観測は、視野・照明・スマホの前面状態・ネットワークを確認します。
- `front_obstacle_unknown`はカメラだけでなく、別ボタンの走行許可と通信を確認します。
- 非常停止・`ironx_rearm_required`は実停止と原因を確認します。
- 停止確認失敗は操作者が復旧します。実停止確認の代わりに解除やサーバー再起動を繰り返さないでください。

非常停止の解除は、サービスを止め、その操作権を解放（または所有ページを離脱）してから
`/console?service=carry`で**Acquire control → Clear E-stop**を操作します。
表示が消えたことを確認して**Release control**し、Serviceに戻って許可・開始をやり直します。
他の操作者から操作権を奪わないでください。再接続だけでは再開しません。

## 設定と確認範囲

Adapter上限・追従プロファイル・通信復旧はUIの走行許可とは別です。
[連続追従試験](continuous-follow-trial.ja.md)、[Adapter](ironx-adapter.md)、
[運用](../operations/runbook.md)を参照してください。
過去のprobe速度や短距離ステップの説明を、選択中の追従設定と混同しないでください。
試験前に有効な設定を確認します。

過去のスマホ追従の成功報告は、その時点の設定に対する記録です。
共通UIの実機操作、停止距離、Windows運用、実機マーカー案内は今回のシミュレータ検証では保証しません。
マーカー案内はService・Playgroundとも実機では無効です。
