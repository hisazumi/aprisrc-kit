# APRISRC Kitの目的と位置づけ

[English](positioning.md)

**APRISRC Kit**は、APRISのロボットチャレンジ **APRISRC** に向けたサービス試作用の開発キットです。
参加者がdevice driverや通信処理から始めず、ロボットの移動と認識・対話を組み合わせた
サービスを作るための共通機能を提供します。

## 名称と役割

| 名称 | この資料での意味 |
| --- | --- |
| APRIS | カンファレンス。ソフトウェアの名称ではない |
| APRISRC | APRISに関連するロボットチャレンジ |
| APRISRC Kit | この開発キット。ソフトウェア、Simulator、サンプル、テスト、ガイドを含む |
| 参加者のサービス | 参加者がKitを使って設計する利用体験と振る舞い |

この資料はKitの実装と使い方を説明するもので、競技規則や審査基準ではありません。
公式・必須のチャレンジ基盤と断定するものでもありません。
イベント固有の要件と正式な位置づけは運営側が別途定める必要があります。

## 参加者が作るのはサービス

誰のどんな場面を支援するか、ロボットが何をするか、人がどう働きかけるか、成功・失敗時に
どう振る舞うかを参加者が決めます。その判断をmission、設定、必要に応じてサービス用UIに実装します。

Kitは認識・対話入力、高水準移動API、Simulator、参照機材との接続、runtimeの安全確認、
開発画面を提供します。操作権、指令の期限、移動上限、停止機構はserver/firmwareが担当し、
サービスを動かすために参加者が迂回してはいけません。

挨拶・追従・荷物運び・マーカー案内は**参考サンプル**で、課題の指定解やサービス完成の証明ではありません。
APIの使い方、変更の効果、失敗時の扱いを具体的に試す出発点です。サービスの方針は変更・置換でき、
サンプル通りに動くことをチャレンジの目標とはしません。API例だけでサービスの利用体験が完成するわけでもありません。

## Simulatorと実機

Simulatorは同じ高水準サービスロジックを、再現可能な仮想観測で実行・変更する場所です。
Simulator専用アプリを別に作るためのものではなく、実カメラ認識・移動精度・停止距離を保証するものでもありません。

現在の実機参照構成はUGV02、車載スマホ、ローカルserverです。Kitの確認対象となる構成であり、
APRISRCがその機材を必須とするという意味ではありません。別のrobot/sensorにはadapter/clientの
contractと個別検証が必要です。[機材と移植条件](hardware/service-hardware-porting.ja.md)を参照してください。

実績と制約は[Platform status](platform-status.ja.md)を参照します。従来の監督付きUGV02追従は確認済みですが、
新実機Playgroundは実機未検証で、実機marker案内も未検証です。無人自律走行や一般的な障害物回避は保証しません。

## 資料と変更範囲

まず[APRISRC Kitを試す・変更する・引き継ぐ](handoff.ja.md)から実習や参加者向けquickstartへ進みます。
`/app`はサービス用、`/lab`はコード・観測を見る開発用、`/console`は操作・監視用です。
サービスによって利用者UIも設計する必要があります。[ロードマップ](roadmap.ja.md)はKit開発の計画で、
イベントの締切や競技課題ではありません。

英語を正本とし、日本語訳は冒頭から開きます。旧名称 **APRIS Rover Platform** は過去の記録に残します。
公開repo/root package名は`aprisrc-kit`です。server/PWA package名、`APRIS_*`設定、protocol名、
証明書label、firmware識別子は技術上の互換名として維持します。特に **APRIS Rover WebSocket protocol** はserver/device間のcontract名で、
カンファレンスやKit全体の名称ではありません。

この公開版は現行コードとガイドを含み、privateの検討履歴は含みません。
