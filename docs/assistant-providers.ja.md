# 音声指示の解釈プロバイダー

[English (canonical)](assistant-providers.md)

音声の文字起こしはブラウザが担当し、その後の文章をサーバーで解釈する。
サーバー環境の`APRIS_ASSISTANT_PROVIDER`で`rules / openai / gemini`を選ぶ。
変更後はロボットを停止した状態でサーバーを再起動する。

| 設定 | APIキー | モデル |
| --- | --- | --- |
| `rules` | 不要。設定済みのキーも使わない | 外部LLM通信なし |
| `openai` | `OPENAI_API_KEY` | `APRIS_ASSISTANT_MODEL`、既存既定値`gpt-6-luna` |
| `gemini` | `GEMINI_API_KEY` | `APRIS_ASSISTANT_MODEL`、既定値`gemini-3.8-flash` |

クラウドを明示選択してキーがない場合は設定エラーになる。
互換性のためプロバイダー未指定なら、従来通りOpenAIキーがあればOpenAI、なければrules。
Geminiキーだけを設定しても自動的には外部送信しない。新規設定では明示選択を推奨する。
モデルは利用アカウントで使用できるものを指定する。Geminiモデル名に`models/`は付けない。
APIキーはサーバーの非公開環境に置き、ブラウザコードやリポジトリには保存しない。

`/api/assistant/status`で選択モードとモデルを確認できる。解釈結果の`source`は実際に判断した
プロバイダーを示し、fallback時には`rules`となる。まずテキストの解釈だけで確認する。
解釈API自体はモーターを操作しないが、動作中のサービスは結果に応じて行動することがある。

停止キーワードはLLMより先にローカル処理する。結果はスキーマと登録済み行動一覧で検証し、
Geminiの拒否・出力途切れ・不正JSON・未登録行動・通信失敗では既存のルール判定へ戻す。
fallbackでもキーワードが一致すれば行動が選ばれるため、必ず停止するという意味ではない。
操作権・指令期限・前方確認・停止の仕組みは変更しない。音声停止は緊急停止の代わりにしない。

Gemini Developer APIの`generateContent`対応であり、Vertex AI対応ではない。
送るのは文章と登録行動の説明・例であり、この経路ではカメラ画像や音声データを送らない。
プロバイダーの料金・データ取り扱い条件は別途確認する。
テストは模擬応答によるもので、実際のキーによる通信や実機サービスの検証は未実施。
